# OpenAgent -- Modular AI Agent Framework

[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue)]()
[![License: MIT](https://img.shields.io/badge/license-MIT-green)]()

**OpenAgent** is a modular, production-ready AI Agent framework.

## Quick Start

```bash
git clone https://github.com/cheche089/agent-framework.git
cd agent-framework
pip install httpx>=0.27
```

Set your API key as environment variable (e.g. OPENAI_API_KEY)

### Run
```bash
python examples/run_agent.py
python examples/run_webui.py
```

## Features
- Tool System, Internet Search, Multi-Provider LLM
- Skill System, Agent Loop, Safety Engine
- Web UI, Docker Sandbox, Workflow Engine
